# Next experiment decision

**No experiment was run for this audit.** This document is a recommendation only. Historical results, data and model artifacts remain untouched.

## Decision: next computational packet

Prioritize a **mostly-clean fault-prevalence and validation-only calibration analysis from existing saved prediction scores**, with the frozen candidate methods limited to clean-trained ResNet, physics-aware ResNet, chest-only ResNet and the Huang→predicted-correction→clean-ResNet chain. This is the smallest next packet that answers a practical question left open by the current evidence: at explicitly hypothetical fractions of the simulated RA–LL fault, how do ranking, probability calibration and fixed-threshold errors trade off?

Reuse existing clean/reversal scores, validation outputs, checkpoint/normalization manifests, and patient/record cluster identifiers. Freeze calibrators and operating points on validation data only; use source-test scores only for the subsequent estimate and keep all variants of one ECG in the same bootstrap cluster. If the Huang pipeline lacks a permissible validation score set, do not calibrate it on HEEDB/test results; report its raw-score sensitivity analysis separately or defer that comparison. Report q_fault as a scenario grid (for example 0, 0.1%, 0.5%, 1%, 5%, 10%, 100%), not as measured prevalence. Recompute AUPRC/AUROC from the mixture distribution rather than averaging condition-level AP. Report sensitivity/specificity, predicted-positive fraction, Brier, ECE/reliability and uncertainty. Existing test access means this is a **reanalysis/exploratory package**, not a new untouched confirmation.

This is higher priority than another augmentation-probability sweep because it reuses predictions and tests whether an observed all-fault recovery has practical relevance under mostly-clean scenarios. It also compares with chest-only and Huang, against which the project has not established an RA–LL TWA-AUPRC advantage. It does not estimate actual cable-error prevalence or confer clinical utility.

## Experiments that do not become mandatory just because they were listed

All candidate architectures × all augmentation modes × all fault families is not justified. Founder mitigation, Transformer Ningbo, all p_aug levels, held-out compositions, external HEEDB chest-only, and a new Cao-inspired model are extensions that should be selected only if their corresponding claim is retained. The single next compute packet above uses existing outputs and does not automatically trigger training.
