# Search log: novelty reassessment

**Search date:** 2026-10-17 (UTC/date set by the project environment).  
**Scope:** Primary publications and official repositories closest to 12-lead ECG reversal robustness, physically plausible lead transformations, lead masking/reduced-lead learning, and detection/correction. The search started from Cao et al. (2020), its reference trail and papers on the same fault family. It was not intended as an exhaustive systematic review.

## Search boundaries and unresolved checks

- Search date, queries and primary links are recorded so the search can be updated; citation counts and current repository state may change.
- No exhaustive citation-chasing database export was performed. The focused searches found no support for an absolute claim that the broad idea of ECG robustness to lead permutations is new.
- The Cao PDF is a five-page primary proceedings paper. Although direct PDF opening timed out, the paper's indexed extraction surfaced all pages and key tables; this is sufficient for the bounded review but an independent local PDF download should be retained with the manuscript source packet if the project needs a permanent audit copy.
- Huang's full publisher text was not accessible through the search reader. We therefore restrict assertions to the PubMed abstract and the authors' public repository README/code inventory.
- For AiTiALVSD, supplement and full text are linked from the primary article. This audit does not claim the model weights or raw patient data are openly downloadable.
- “Not reported/not found in the accessible text” is used as a local search result, not as proof that a topic has never been studied.
