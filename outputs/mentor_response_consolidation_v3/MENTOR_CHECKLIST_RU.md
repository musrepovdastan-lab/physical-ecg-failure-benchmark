## Правила подачи чисел

- Каждое число выше привязано к TWA, когортам и условию; для полной таблицы см. `SOURCE_INDEX.md` и исходную строковую CSV.
- Разность metric A−B имеет знак, указанный рядом; для Brier меньшая величина лучше, для AP/AUROC большая лучше.
- Sensitivity без specificity / FP на 1,000 неполна. Снижение ошибки по одной метрике не отменяет проигрыш по другой.
- HEEDB extensions используют одни и те же 10,000 ранее просмотренных пациентов и proxy labels; это не несколько независимых внешних проверок.
- Пересечение 95% CI с нулём — неопределённый эффект, не доказательство эквивалентности.
