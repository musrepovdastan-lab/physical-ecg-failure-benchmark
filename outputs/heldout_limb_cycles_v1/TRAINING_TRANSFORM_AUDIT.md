# Аудит обучающих преобразований для циклов holdout

## Вывод

В просмотренных обучающих путях два проверяемых цикла не генерировались как преобразования одного примера. Каждое обучающее представление получает либо чистый сигнал, либо одну маску, либо один физический swap. Последовательного применения swap→swap к одному примеру в этих реализациях нет. Поэтому циклы являются unseen-комбинациями внутри изученного семейства перестановок terminal electrodes, а не новой семьёй физиологических сбоев.

## Просмотренные реализации

- Chapman M1: `src/mitigation_m1_v1.py`, `augmented` (строки 55–63). Physics-aware выбирает clean или один reversal; masking — clean или одну маску; combined выбирает одну категорию clean/mask/reversal. При reversal выбирается один из RA–LA, RA–LL, LA–LL.
- Ningbo physics-aware: `src/mitigation_m2_ningbo_v1.py`, `augment` (строки 51–54). Для примера выбирается один из трёх named reversals.
- Ningbo four-arm: `outputs/ningbo_four_arm_replication_v1/workflow.py`, `augment_raw` (строки 86–96). Для combined фиксированы вероятности clean 0.5, одна маска 0.25, один reversal 0.25; протокол задаёт `never_combine: true`. Для physics-aware используется clean либо один reversal.
- Ordinary и chest-only контрольные модели не обучались на циклах: ordinary не получает такую аугментацию, chest-only использует только V1–V6.

## Проверенные условия

`cycle_slots_120=(1,2,0)` совпадает с последовательным применением RA–LA, затем LA–LL. `cycle_slots_201=(2,0,1)` совпадает с LA–LL, затем RA–LA. Оба преобразования взаимно обратны, и каждое имеет порядок 3. Инженерная проверка сверила формулы независимым расчётом и подтвердила инвариантность грудных отведений.
