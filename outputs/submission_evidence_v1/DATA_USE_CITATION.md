# HEEDB v5.0 citation and release gate — checked 26 September 2026

The [BDSP HEEDB v5.0 record](https://www.bdsp.io/content/heedb/5.0/) asks users to cite Koscova et al., *Harvard-Emory ECG Database*, version 5.0, BDSP (2026), [doi:10.60508/rv6h-7d10](https://doi.org/10.60508/rv6h-7d10), **and** the original publication linked there as a [2024 medRxiv preprint](https://doi.org/10.1101/2024.09.27.24314503). A published version of record is now available: Koscova et al., *Scientific Data* 13, 516 (2026), [doi:10.1038/s41597-026-06861-9](https://doi.org/10.1038/s41597-026-06861-9). Cite the dataset DOI and the published paper in the manuscript; retain the repository-requested preprint citation in final bibliography if BDSP confirms it remains separately required.

**The article's open-access license is not the data-file license.** The current v5.0 data files are under the [BDSP Credentialed Health Data License 1.5.0](https://www.bdsp.io/content/heedb/view-license/5.0/) and [BDSP credentialed DUA](https://www.bdsp.io/content/heedb/view-dua/5.0/). They restrict access to credentialed/approved users, require security and noncommercial research use, prohibit reidentification and onward sharing of data and record-level derivatives, and prohibit uploading them to platforms that permit unapproved third-party access. The license also calls for code associated with publications to be contributed to an open research repository; code release must therefore be prepared separately without restricted paths, data, secrets or record-level outputs and reviewed against the executed DUA/institutional policy.

**Release decision:** No public ECG trace, record-level prediction, cohort manifest, header, diagnostic row, or reconstructed patient example from HEEDB is proposed or included. This folder contains aggregate tables and figures only. Before *any* public release, the data steward/institution should review the final aggregate disclosure risk, the executed DUA, code package, venue policy, and whether BDSP written approval is needed. A synthetic algebra illustration generated without HEEDB records could be considered later; it has not been made here. No file was submitted or sent externally.
